# Catálogo de projetos em PostgreSQL

Eu modelei um catálogo simples de projetos com tecnologias associadas. O script cria tabelas relacionais, chaves e uma consulta de leitura com agregação.

## Executar

Com PostgreSQL disponível, execute: `psql -d portfolio -f schema.sql`.

## O que pratiquei

Modelagem relacional, chaves estrangeiras, restrições e consulta SQL.
